Description: \
tikz-lua3dtools is a toolkit for making 3D illustrations with Ti*k*Z. 
It can render multiple parametric objects and labels at once, and 
clip planes by rectangular prisms. Eventually, I want to add triangle
clipping.

Change Log: \

v0.01:
- Robust triangle sorting, rudimentary line segment sorting.
- Division by zero handling.
- Clipping of individual planes by rectangular prisms.
- Geometric vector commands.
