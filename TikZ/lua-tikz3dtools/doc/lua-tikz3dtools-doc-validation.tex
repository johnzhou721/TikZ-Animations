\subsubsection{Point Versus Point}

In Figure \ref{fig:validation-point-versus-point}, the green point 
should occlude the red point, but no other ordering is necessary.
That is to say, as long as the green is on top of the red dot, it 
doesn't matter what order the rest are in. The test is given by 
\begin{verbatim}
\begin{tikzpicture}
    % The greed point should appear on top of the red point.
    \appendpoint[
        x = {0}
        ,y = {0}
        ,z = {0}
        ,transformation = {identity_matrix()}
        ,fill options = {fill = red}
    ]
    \appendpoint[
        x = {0}
        ,y = {0}
        ,z = {1}
        ,transformation = {identity_matrix()}
        ,fill options = {fill = green}
    ]

    % There is no occlusive relationship between these points,
    % or between them and the first two.
    \appendpoint[
        x = {1}
        ,y = {0}
        ,z = {0}
        ,transformation = {identity_matrix()}
        ,fill options = {fill = blue}
    ]
    \appendpoint[
        x = {0}
        ,y = {1}
        ,z = {1}
        ,transformation = {identity_matrix()}
        ,fill options = {fill = black}
    ]
\end{tikzpicture}
\end{verbatim}
