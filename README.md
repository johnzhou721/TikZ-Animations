# Ti*k*Z-Animations

Welcome to **Ti*k*Z-Animations**, a personal hobby project dedicated to creating high-quality TeX-based animations leveraging the power and flexibility of TikZ, Lua, MetaPost, and ConTeXt.

---

## Project Overview

The goal of Ti*k*Z-Animations is twofold:

1. **Share cool animations to inspire others**  
   I love making animated TeX illustrations, and wanted to share them
   with people.

2. **Share useful code which can do things that current codes cannot**  
   In making these animations, I've developed code which improves on 
   current graphical capabilities in TeX.

---

## Example Animations

### 1. Rotating Parametric Curve  
![Rotating Parametric Surface](Animations\spinning_shell.gif)  
A smooth 3D parametric curve rotating around an axis, rendered purely in TikZ using Lua for geometry computations.

### 2. Animated Möbius Transformation  
![Möbius Transformation](Animations\mobius_transformation.gif)  
Visualization of a Möbius transformation acting on the complex plane, illustrating conformal mapping with continuous animation.

### 3. MetaPost-ConTeXt Accelerated Animation  
![MetaPost Animation](Animations\letter_transformation.gif)  
A fast-rendering animation using the MetaPost-ConTeXt-Lua pipeline, demonstrating the performance advantages over pure TikZ.
