# Source Code for YouTube Videos — Jasper Math Illustrations

This repository contains the source code used to create the animations featured in my YouTube channel: [Jasper Math Illustrations](https://www.youtube.com/@JasperMathIllustrations).

The mathematical theorems and constructions follow the sequence presented in *Euclidean Geometry: A First Course* by Dr. Mark Solomonovich. I gratefully acknowledge Dr. Solomonovich for his excellent text and his kind permission to share these materials.
